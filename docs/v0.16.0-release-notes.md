# VoteKit v0.16.0 — Public polls

## New participation type
Owner and Returning Officers can use **Admin Panel → Public polls** to create a draft, review/edit its options and dates, and open a shareable public link. Anyone with that link can submit without a roll, account or invitation. Existing election modes and permissions are unchanged.

This first version supports one optional-ranked question, a self-declared Greens membership question, and email confirmation after submission. Ranked preferences use the existing Condorcet/Schulze counter. Options and dates become immutable when opened.

## Confirmation and results
- Email links require an explicit Confirm ballot button; opening a link does not confirm it.
- Links last up to 48 hours, bounded by the organiser’s confirmation deadline.
- One accepted ballot per normalised email; the first successful confirmation selects the ballot for that address. Older pending links are not cancelled by retries.
- Retry and network limits reduce abuse, but neither email nor IP establishes a unique person or verified membership.
- Finalise after the confirmation deadline, then separately publish aggregate results: all accepted ballots, email-confirmed ballots, and confirmed ballots from self-declared members.
- No live preferences, individual ballot export or automatic publication.

## Privacy
Ballots have no email, IP or timestamp fields. Verification details and their temporary ballot linkage are encrypted using a separate per-poll key. Restricted abuse review shows network counts and timing, not email addresses or preferences. Finalisation deletes verification records and the separate key, shuffles retained ballots and replaces their IDs. Key-removal failure leaves results locked for safe retry.

This is confidentiality during voting, not operator-proof anonymity. Host snapshots, forensic file recovery and retained transport logs remain separate risks. Managed SQLite backups exclude keys. Loss of a key prevents pending confirmations; keys must not be recreated for opened polls.

## Operations
Set PUBLIC_POLL_KEY_DIR to an absolute, private directory outside managed database backups. Production uses /var/lib/votekit/public-poll-keys, owned by the runtime user, mode 0700, with key files mode 0600. No actual leadership poll is created or opened by this release, and no participants are emailed automatically.
