# VoteKit v0.15.3 - Owner-assisted password reset

- Adds **Send password reset** in Organisation Roles for active Returning
  Officers, Admins and Observers. Only the Owner can send these emails.
- Uses the account's existing email address, without deactivating the account or
  altering roles and election assignments.
- Recipient chooses and confirms a new password through a 30-minute, single-use
  email link, then signs in normally. Completing the reset signs out existing
  account sessions and sends a password-changed notification.
- New requests replace old links. Account changes invalidate outstanding links.
  Requests are rate limited, and delivery failures cancel the undelivered link.
- Reset tokens are stored only as hashes; passwords and raw tokens are excluded
  from API responses and audit logs. Sending and completion are audited.
- Owner-account recovery and public self-service reset requests are not part of
  this release. Invitation and election permissions remain unchanged.

The database change adds the recovery table only. No existing passwords are reset
and no reset emails are automatically sent during deployment.

Design and security rationale: [Owner-assisted password recovery](admin-password-reset.md).
