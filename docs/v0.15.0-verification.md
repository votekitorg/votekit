# v0.15.0 verification

Verified 23 September 2026 before release.

- Clean dependency install with `npm ci`.
- Automated suite: 143 passed, one production-copy rehearsal test skipped in the
  normal suite. That rehearsal passed separately against a private production copy.
- Lint, TypeScript, regression check and production build passed.
- Full dependency audit: zero vulnerabilities.
- Migration rehearsal: all original fields and rows across all 31 original
  tables remained identical. Additive columns/table only; integrity check passed.
- Chromium production-build checks at 320, 390 and 430 pixels: empty initial
  rankings, missing-answer focus, progress, order preservation, visible stale
  deadline errors, retained choices and no horizontal overflow.
- Browser checks distinguish closed, missing and failed election loads, and
  verify current-password versus new-password invitation fields.
- Isolated admin browser flow extended an expired deadline, displayed its history
  and changed the finalisation action label appropriately.
- SFC browser flow changed and saved the comparison rule; review and public proof
  displayed the persisted rule.
- SFC unit/integration tests cover exact threshold boundaries, partial rankings,
  zero preferences, failed leaders, all failing, ties, exports and recounts.
- Deadline integration tests cover permission/CSRF, validation, stale edits,
  immutable history and encryption/recovery compatibility before and after an
  extension.

Browser fixtures used an isolated database and mocked voter APIs. No test emails
or SMS were sent. Actual iPhone Safari Password AutoFill/Keychain behaviour remains
unverified; correct field semantics were verified in Chromium, not on an iPhone.
