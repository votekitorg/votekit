# VoteKit v0.12.8

## Owner oversight and draft recovery

- Organisation Owners can see all election setup drafts on the dashboard,
  labelled with their creator.
- Owners can open the existing read-only proof view without changing ownership.
- Editing remains restricted to the current creator by default.
- An Owner can explicitly take over another creator's draft after a clear
  confirmation. The previous creator then loses edit access and the transfer is
  recorded in the administrator audit log.

## Verification

- Route tests cover non-Owner denial, successful Owner takeover, audit logging,
  and edit-access transfer.
- Full application tests, lint, type checking, regression checks, production
  build and dependency audit pass.

This release does not change ballots, published elections, or voter data.
