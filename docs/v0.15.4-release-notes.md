# VoteKit v0.15.4 - Self-service password recovery

- Added **Forgot password?** to the sign-in page. Active account holders,
  including Owners, can request their own password-reset email.
- Links remain single-use and valid for 30 minutes. Request the link when ready
  to use it, without needing an Owner to deactivate or re-invite the account.
- Existing Owner-assisted **Send password reset** remains available.
- Reset requests show the same response for existing, missing, inactive and
  throttled addresses. Account lookup and delivery run after the response.
- Separate per-address, IP and global request limits reduce email abuse without
  locking normal sign-in. Repeated public requests do not cancel older valid links.
- Completing a reset signs out existing sessions and invalidates other reset
  links, without changing account roles, activation or election assignments.
- Invalid or expired links lead back to self-service recovery.
- No passwords changed or reset emails sent automatically during deployment.

The migration preserves existing reset records while allowing an unauthenticated
self-service request to be distinguished from an Owner-assisted request.
