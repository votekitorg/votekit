# VoteKit v0.12.7

## Election draft autosave safety

- Serialises rapid autosaves in the browser so they reach the server in the
  same order the organiser made them.
- Adds monotonic draft revisions and rejects stale updates with HTTP 409 rather
  than allowing old form data to overwrite newer work.
- Keeps Save & Exit on the form with a clear error unless the newest version is
  confirmed saved.
- Prevents publication from continuing when the final draft save fails.

## Verification

- Regression coverage confirms queued saves remain ordered, a failed request
  does not break the queue, and stale revisions cannot replace current data.
- Full tests, lint, type checking, regression checks, production build and
  dependency audit pass.

The schema change is additive and backward compatible. Code rollback may leave
the unused `revision` column in place safely.
