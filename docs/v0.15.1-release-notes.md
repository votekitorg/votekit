# VoteKit v0.15.1 - Elections-first admin

- Retains the existing Admin Panel sidebar, colours and typography.
- Replaces dashboard totals and oversized shortcuts with a searchable election
  list showing status, relevant Brisbane dates and the next action.
- Search covers all accessible elections, not just the ten most recent.
- Filters separate editable drafts, published/not-open elections, open voting,
  elections awaiting finalisation and finalised results.
- Preserves draft continuation, proof links and audited Owner takeover.
- Archives remain Owner-only; observers receive view-only actions.
- Finalise links open the existing management workflow, not a one-click count.
- Responsive rows and wrapping filters work on narrow screens.

## Permissions fix discovered during acceptance testing

The legacy organisation-wide-to-election-scoped role migration previously repeated
its access backfill on startup. It now seeds assignments only when the election
team table is first created, preventing future restarts from restoring revoked
access or granting access to unrelated elections. Existing assignments are
preserved; this does not retrospectively identify or remove earlier grants.
A regression test verifies scopes and revoked assignments across a cold restart.

No schema, ballot, counting-rule or voter-facing changes. CiviCRM remains deferred.
