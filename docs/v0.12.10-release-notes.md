# VoteKit v0.12.10

VoteKit v0.12.10 makes multi-question results easier to review and applies two
targeted build-tool security patches.

## Changes

- Published ballot receipts are collapsed by default beneath each question's
  result, keeping the next question summary close at hand.
- Each collapsed section shows the number of anonymous receipts available and
  retains the full ballot verification explanation and table when opened.
- Privacy-threshold suppression, private receipt lookup, result calculations and
  stored election data are unchanged.
- `js-yaml` is patched from 4.3.0 to 4.3.2.
- `nanoid` is patched from 3.3.16 to 3.3.18.
- Regression coverage protects the collapsed results layout.

This release has no database migration and does not alter elections, voters,
ballots, counts, results or access controls.

## Release procedure

1. Confirm the candidate branch is clean.
2. Run `npm ci`, `npm run lint`, `npm test`, `npm run regression-check`,
   `npm run type-check`, `npm run build`, and `npm audit --audit-level=moderate`.
3. Review database migration and rollback implications.
4. Merge and push the approved commit.
5. Create and push the annotated `v0.12.10` release tag.
6. Verify automated production deployment, `/api/health`, the results page and
   the deployment backup.
